# CineNova (hay que cambiarlo)

## Requisitos

- PHP 7.4 o superior con la extensión `pdo_sqlite` activada

## Iniciar en local

1. Crear la base de datos (solo la primera vez):

   ```
   php database/instalar.php
   ```

   Al terminar muestra la cuenta de administrador (`admin@cinenova.local`) y su contraseña, una sola vez.

2. Iniciar el servidor desde la carpeta del proyecto:

   ```
   php -S localhost:8000
   ```

3. Abrir <http://localhost:8000> en el navegador.


4. Aquí el link para la pagina web: proyecto-cine.alwaysdata.net/
